# Name plugin-rust-v0.2.1 Implementation Plan

**Goal:** Every file in the repository that pins or shows the rust plugin names version 0.2.1.

**Architecture:** No behaviour changes. The plugin's `extension.toml` becomes 0.2.1;
`buildl-cargo`'s `RUST_PLUGIN_TAG` becomes `plugin-rust-v0.2.1` and the crate 0.1.2; the
examples, the book, the skills and the CHANGELOG follow. The tag itself is plan 02, after merge.

**Tech Stack:** Rust (`buildl-cargo`), Lua plugin manifest, TOML, Markdown, shell (`prepare.sh`).

**Content authority:** `intent.md` (spec skipped). Every outcome below is the intent's "Desired outcome".

## Risks

- Until plan 02 pushes the tag, `plugin-rust-v0.2.1` exists only as the examples' local tag: a
  `buildl plugins fetch` from GitHub of the new `rev` fails. The PR merges with that gap, closed by
  plan 02 right after.
- `cargo make examples` runs `examples/check.sh`, which needs `python3` (`examples/check.sh:56`),
  and the examples need their own tools (`go` for `examples/polyglot`); without them Task 3's
  check cannot run and the record says so.
- Riskiest step: Task 4's recorded output, which depends on running two examples; the run, not
  hand edits, decides each line.

# Appendix

The chapters teach `buildl` one idea at a time. The appendices are for looking things up. A to D
are read from the code and the binary of this version, not from the design documents, so where the
two ever disagree, the appendix says what `buildl` actually does.

| Appendix | What it holds |
|---|---|
| [A. Command-Line Reference](appendix-01-cli.md) | every command, its arguments and flags, and the environment variables `buildl` reads |
| [B. `buildl.toml` Reference](appendix-02-buildl-toml.md) | every table and key `buildl.toml` accepts, with its type, default and meaning |
| [C. Build File API](appendix-03-lua-api.md) | every function of the `buildl` table a build file calls, and what it accepts and returns |
| [D. Exit Codes](appendix-04-exit-codes.md) | the eight exit codes, 0 to 7, and what ends in each |
| [E. References](appendix-05-references.md) | the papers, specifications and tools the design draws on |
